# Expense Tracker

A simple command-line expense tracker built with Python.

## Features
- Add expenses (date, category, amount)
- Data saved in a CSV file
- Total spending
- Category-wise spending
- Monthly summary using pandas
- Input validation (date and amount)

## How to run
1. Install Python 3
2. Install pandas: pip install pandas
3. Run: python expense.py

## What I learned
Python basics, file handling, functions, dictionaries, try-except, pandas
